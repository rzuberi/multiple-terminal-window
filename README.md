# multiple-terminal-window

`multiple-terminal-window` is a simple Electron app that opens multiple live terminal windows in one desktop app.

## What it does

- Spawns interactive terminal sessions
- Shows each session in its own window card
- Lets you open more terminals with one click
- Lets you optionally choose a working directory before spawning a terminal

## Requirements

- macOS
- Node.js
- npm

## Install

```bash
git clone https://github.com/rzuberi/multiple-terminal-window.git
cd multiple-terminal-window
npm install
```

## Run

```bash
npm start
```

## Notes

- This is an early v1 prototype focused on terminal spawning.
- The larger workspace features like draggable layouts, focus zones, and keyboard shortcuts are not implemented yet.
